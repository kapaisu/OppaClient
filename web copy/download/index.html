Windows

Windows 10 and 11, 64-bit

Oppa-Setup.exe

Windows may warn about an unknown publisher on first run. Choose More info, then Run anyway.

Arch Linux

Add the Oppa repository to /etc/pacman.conf

[oppa]
SigLevel = Optional TrustAll
Server = https://github.com/kapaisu/OppaClient/releases/download/repo

Then install it, and update with the rest of your system

sudo pacman -Sy oppa

Other Linux

Any distribution with Flatpak. Add the source once

flatpak remote-add --user --if-not-exists oppa https://kapaisu.github.io/OppaClient/oppa.flatpakrepo

Then find Oppa in your software store, or install it here

flatpak install --user oppa dev.oppa.Launcher
